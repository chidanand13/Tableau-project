# Breaking Bad Dashboard

This is a Tableau dashboard project analyzing the TV show *Breaking Bad*.  

## 📊 Features
- Includes episode counts, IMDB ratings by season, director contributions, and U.S. viewership trends.
- Episode ratings visualization
- Storyline insights

## 📂 File
- `BB TV Show.twbx` → Tableau packaged workbook (open with Tableau Desktop)

## 🚀 How to Use
1. Download the `.twbx` file
2. Open it in Tableau Desktop
